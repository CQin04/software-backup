## 使用

1. 完整解压 ZIP，选择颜色主题、尺寸和样式。
2. 右键对应样式中的 `~右键安装.inf`，选择“安装”；需要时先点“显示更多选项”。
3. 打开 Windows 的鼠标属性 → 指针，确认方案并应用。

保留同级 `base` 文件夹及完整目录结构，不要只提取单个样式。原安装文件中多组样式共用安装路径和方案名称，切换安装可能覆盖原方案。`alternatives` 保存可手动选用的替代指针。
