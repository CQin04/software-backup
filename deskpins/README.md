# DeskPins 1.32

窗口置顶工具，作者 Elias Fotinis。

## 下载与使用

- [Release 下载页](https://github.com/CQin04/software-backup/releases/tag/deskpins-1.32)
- [下载 DeskPins-1.32-setup.exe](https://github.com/CQin04/software-backup/releases/download/deskpins-1.32/DeskPins-1.32-setup.exe)
- [SHA256 校验值](SHA256SUMS)

安装并启动后，点击托盘中的 DeskPins 图标，再点击需要置顶的窗口。
