# NanaRun 1.0 Preview 3

版本：1.0.92.0，预览版。

NanaRun 是 M2-Team 的 Windows 运行环境工具集，本包包含 MinSudo（以不同权限运行程序）和 SynthRdp（远程桌面会话工具）。

## 下载与使用

[Release 下载页](https://github.com/CQin04/software-backup/releases/tag/nanarun-1.0.92.0) · [下载原版 ZIP](https://github.com/CQin04/software-backup/releases/download/nanarun-1.0.92.0/NanaRun_1.0_Preview3_1.0.92.0.zip)。

解压后，按设备选择 `x64`、`ARM64` 或 `Win32` 目录；操作方法见包内 `ReadMe.txt`。ZIP 原样保留，包含上游调试符号文件。校验值见 [SHA256SUMS](SHA256SUMS)。
